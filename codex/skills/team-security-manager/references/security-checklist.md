# Security Checklist

Use this for threat modeling and security review.

## Inspect

- assets and trust boundaries
- authn and authz
- secrets exposure
- untrusted input and injection
- command execution
- external integrations
- data leakage
- dependency risk

## Decide

- fail-open or fail-closed
- mitigations needed now
- validation still missing

## Output Shape

- severity
- attack or failure path
- mitigation
- validation gap
