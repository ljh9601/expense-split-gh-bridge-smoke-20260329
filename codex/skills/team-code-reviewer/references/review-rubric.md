# Review Rubric

Use this for findings-first review.

## Look For

- behavioral regressions
- incorrect assumptions
- missing tests
- stale docs or config
- broken packet boundaries
- unsafe failure handling

## Severity

- high: correctness, security, data loss, or major regression
- medium: likely bug, missing validation, or notable maintainability risk
- low: minor risk or cleanup that still matters

## Output Shape

- findings first
- file references where possible
- open questions only if risk-relevant
- brief summary after findings
