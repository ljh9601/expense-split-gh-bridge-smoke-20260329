# Research Checklist

Use this when gathering references.

## Source Quality

- Prefer primary or authoritative sources.
- Check freshness when the topic can change.
- Record the exact link used.

## Research Flow

1. Narrow the question.
2. Gather the minimum credible sources.
3. Extract only decision-relevant facts.
4. Mark inference separately from verified fact.

## Output Shape

- question
- key findings
- source links
- design implications
- open unknowns
