# Pull Requests

이 디렉터리는 packet 단위 로컬 PR 산출물을 보관한다.

- `WP-001-pr.md`: 한글 PR 본문
- `WP-001-pr.yaml`: 브랜치, 상태, 승인자 등 기계 판독 메타데이터
- `WP-001-review-comment.md`: Codex 리뷰 코멘트

원칙:

- packet 하나는 논리적으로 PR 하나에 대응한다.
- 실제 GitHub PR 브리지가 없더라도 로컬 git 이력과 이 폴더만으로 무엇이 왜 병합됐는지 추적 가능해야 한다.
- 제목과 본문은 한글을 기본으로 유지한다.
- 실제 자동화 커밋 주체와 논리적 작성자는 다를 수 있으므로 둘을 분리해 기록한다.
