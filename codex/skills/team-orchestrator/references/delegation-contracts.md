# Delegation Contracts

Use this before creating or revising a work packet.

## Required Packet Fields

- objective
- why now
- in scope
- out of scope
- owned files or surfaces
- required artifacts
- validation commands or checks
- next gate

## Parallelism Rules

- Parallelize only when write scopes are disjoint.
- Prefer 2-4 specialists for broad work, fewer for tight coding loops.
- Coding is less parallel than research; do not force parallelism.

## Artifact Matrix

- researcher: research note
- product-analyst: acceptance note
- architect: design brief
- programmer: patch plus changed files
- tester: verification report
- security-manager: security review note
- performance-engineer: performance note
- ui-designer: UI spec
- docs-curator: docs delta note
- code-reviewer: findings-first review report

## Closeout Checks

- validation evidence exists
- review happened
- docs state is current
- backlog and handoff state are current
- residual risks are explicit
