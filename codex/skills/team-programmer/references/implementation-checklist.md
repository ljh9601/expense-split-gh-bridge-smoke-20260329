# Implementation Checklist

Use this before and after editing.

## Before

- Confirm owned files or surfaces.
- Confirm non-goals.
- Re-read relevant design or acceptance notes.

## During

- Make the smallest coherent patch.
- Preserve conventions unless the packet changes them.
- Update tests with behavior changes.

## Before Handoff

- List changed files.
- Record validation run.
- Call out residual risks or follow-ups.
