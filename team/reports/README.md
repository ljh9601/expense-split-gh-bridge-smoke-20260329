# Reports

Store packet-level artifacts here when they should survive the chat session.

Suggested naming:
- `WP-001-bundle.yaml`
- `WP-001-design.md`
- `WP-001-research.md`
- `WP-001-verification.md`
- `WP-001-review.md`
- `WP-001-closeout.md`

Rules:
- The bundle file is the canonical index for report paths produced during a packet cycle.
- Keep reports compact, evidence-oriented, and easy for Codex to scan during review.
- Match bundle and run ids with `team/run-state/active-run.yaml` and `team/run-state/run-ledger.jsonl`.
